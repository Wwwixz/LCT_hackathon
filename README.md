# 112-симулятор

Страницы проекта:

```
/
/login
/register
/student
/students
/groups
/teacher
/teacher/students
/admin
/admin/teachers
/admin/students
/admin/group-students
/admin/groups
```

## Описание

| Путь | Страница |
| --- | --- |
| `/` | Главная |
| `/login` | Вход |
| `/register` | Регистрация |
| `/student` | Дашборд студента |
| `/students` | Студенты группы «ДВ 102» |
| `/groups` | Группы (преподаватель) |
| `/teacher` | Дашборд преподавателя |
| `/teacher/students` | Список студентов (преподаватель) |
| `/admin` | Дашборд администратора |
| `/admin/teachers` | Список преподавателей |
| `/admin/students` | Список студентов (администратор) |
| `/admin/group-students` | Студенты группы «ДВ 102» (администратор) |
| `/admin/groups` | Группы (администратор) |

## Запуск

```bash
npm install
npm run dev
```

Dev-сервер: http://localhost:4321
